## 2. 操作感

### 良かった点

- **戦利品の行（haul）が判断の中心として機能した。** 毎回「今帰れば +X・綱なら +Y／次に踏破の点が入る階」が出るので、帰る・進む・綱の比較をその場で計算し直さずに済んだ。
  > `戦利品 6443（目的5175・宝213・賞金480・発見370・撃破205）×1.25 → 今帰れば +8053・綱なら +3221`
- **fight の止まり方がちょうどよい。** first_hit（初めて被弾した種族の数字を見せる）と hp_risk（被弾の前に止まる）が特に良かった。トロル戦で一撃 17 の後に止まってくれたので、攻撃を続けるか退くかを自分で選べた。
- **abilities を載せた fight が楽。** 強打の再使用待ちを数えなくてよい。結果に「能動技: 強打 1 回」と回数が出るのも良い。
- **エラーとヒントが的確。** 気づいていない相手に fight を使ったときの応答:
  > `Error [no_target] その相手はまだあなたを追っていない… Hint: 近づくなら travel_to、先手を取るなら throw_item。`
- **思い出（recall）と推定残り HP** が読みやすい。「記録どおりなら残り 6〜8（記録 3 体）」は、標本だと分かる書き方で好ましい。
- **気配（sense）** の「南東・近い（10 マス以内）」で、遺物探しの方向が分かる。
- **▶ 行**が短く、今が自分の番か・遠征が終わったかが一目で分かる。

### 困った点

- **explore toward:draft が往復して 200 手を浪費した（2 回とも再現）。** 地図はほとんど広がらず、その間にフロア時間が 22000 進んだ（徘徊が数体湧いていてもおかしくない時間）。以後は使わなかった（§6 バグ 1）。
- **explore が目的地を意識しない。** 遺物の気配が「南東」なのに、最寄りの境界（北・西）へ向かって遠回りした。遠くの加速の薬を拾いに戻ることもあった。pickup=false を後から知った。
- **ガラクタを拾い続ける。** 鱗鎧を着ているのに革鎧を 3 枚、短剣を使っているのに小剣を 3 本拾った。valid_actions に `equip a / equip b / equip i / equip j / equip k / equip r` が並び続けて読みにくい。
- **逃げる瀕死の敵が 1 マス幅の通路をふさぐと、travel_to が進まない。** `既知の経路が敵にふさがれていて進めない（マクロは攻撃しない）` が繰り返され、move を手で打つことになって約 10 回の呼び出しを失った（explore の steady・flee は通路をふさぐ逃走中の敵を攻撃するのに、travel_to はしない）。
- **群れの各個体が見えるたびに fight が止まる。** ジャッカル 4 体を相手にしたとき、0 手の停止が 2 回続いた。
  > `fight: 1 手進んだ（0 歩、時間 100）。停止: 敵が視界に入った。 0 回攻撃し…`
  その後も 1 体倒すごとに止まるので、群れ 1 つに 6〜7 回の呼び出しがかかる。
- **「追われたままなら最悪の被害」が過大。** 大ネズミ 1 体に「階段まで 23 歩。追われたままなら最悪 138 の被害（HP 33）」と出た。歩数 × 1 手の最悪の被害なので、同じ速さで追ってくる敵が歩くたびに殴れる前提になっている。数字が大きすぎて判断材料にならず、読み飛ばすようになった。
- **ブリーフィングの量が遠征ごとに違う。** 遠征 1 の開始時は達成条件・撤退・綱・報酬・条件・「情報: 遺物は守護者が守っている」まで出たが、遠征 2・3 は 1 行だけ。遠征 2 は遺物に守護者がいるのかを、候補の「（守護者付き）」が無いことから推測するしかなかった。
- **キャンプの ▶ 行**が「これ以上の行動は不要です」と言う。次の遠征を選ぶ場面なので、続けたい AI には少し紛らわしい（終えてもよい、という意図は分かる）。
- **new_run の応答で候補の一覧が 2 回出る**（結果の部分と状態の部分）。

## 3. ここがこうなってほしい（改善提案）

| 優先度 | 提案 |
|---|---|
| 高 | **explore toward:draft の往復を直す**（§6 バグ 1）。少なくとも「N 手進んだが新しく見たセルが少ない」なら止めて理由を返す |
| 高 | **explore に目的の方向を優先する指定（例: `toward: "sense"`）を加える。** 遺物・守護者の気配の方角の未探索を優先する。今は気配を見ても explore では寄れず、travel_to で境界の座標を手で選ぶことになる |
| 高 | **拾わない対象を広げる。** 装備中の品より明らかに劣る防具・武器は、種類が違っても拾わない（または `pickup: "useful"` を用意する）。valid_actions の equip の列挙も、劣る品は省くか 1 行にまとめる |
| 中 | **travel_to も、1 マス幅の通路をふさぐ逃走中の敵を攻撃して進める mode を持つ**（explore の steady・flee と揃える） |
| 中 | **fight に「群れ」向けの続行オプション**（例: `until: "no_hunting"`。追跡中の敵がいなくなるまで、隣に来た相手を順に殴る）。今の「1 体ずつ・新しい敵で止まる」は安全だが、群れでは呼び出し数が膨らむ |
| 中 | **「追われたままなら最悪の被害」を速さを考えた見積もりにする**（自分より速い敵の分だけ数える、自分の歩く手番コスト 110 を反映する）。今の値は大きすぎて判断に使えない |
| 中 | **起こした原因を知らせる。** 「あなたの攻撃の音で洞窟トロルが目を覚ました」のように。指輪の欠点が効いた場面だったはずだが、因果が見えなかった |
| 中 | **ブリーフィングの量を揃える。** 遠征 2 以降も「遺物は守護者が守っている／守っていない」の 1 行は必ず出す |
| 低 | 所持品の詳細の表記揺れを直す（「balanced」「quick」の英語、命中の値の食い違い） |
| 低 | 盾の構え（brace）の「待機」に fight の待ち手番が含まれるかを説明に書く |
| 低 | new_run の応答で候補の一覧を 1 回にする |

## 4. 楽しみ・モチベーション・動機として不足している要素（最重要）

### 意味のある選択（トレードオフ）
- **現状:** キャンプの 3 択は計算すると答えが出やすい。遠征 1 は野心が明らかに得で、「遺物なら綱で目的込み 50%」という保険があるので、遺物型の候補はほかの型より常に安全に見えた。特技は「+1 威力か +5 HP か」のような数値の比較が多かった。
- **不足:** 3 択がどれも魅力的で、互いに別のものを失う構図。特技は戦い方を変えるものが少なく、能動技を取っても使う場面が来ない。
- **こうなれば動機になる:** 枠ごとに失うものを変える（例: 野心は綱が使えない、堅実は宝が多い、標準は特技の候補が 1 つ増える）。遺物と綱の組み合わせの強さを見直す（綱では遺物を「納めた扱い」にせず、遺物は階段まで運んで初めて点になる、など）。特技に「なぎ払いを取ると、囲まれたときの被ダメージ -1」のような、選んだ技を使いたくなる状況を自分から作る誘導を付ける。

### リスクと報酬
- **現状:** 戦利品の行が良く、深追いの判断は楽しかった（遠征 2 の地下6階への深追いは「逃げ道を確保したまま賭ける」感覚があって一番面白かった）。一方、下り階段の位置が見えないので、遠征 1 の深追いは判断材料が無く、帰るしかなかった。
- **不足:** 深追いの「見込み」。階段がどれくらい遠そうかの手がかり。
- **こうなれば動機になる:** 未発見でも「下への風が強い（近い）／弱い（遠い）」の 2 段階を出す。一度降りた階の階段の位置は、次の遠征の候補に「下見済み」として載せる。

### 成長・ビルドの手応え
- **現状:** 一番の成長は特技ではなく、守護者が落とした補強された鱗鎧（装甲 1→4）だった。地下5階のオークの攻撃がほぼ 1 しか通らなくなり、地下7階まで作業になった。強打は気持ちよかったが、なぎ払い・立て直しは 0 回。回復の薬 4・加速の薬 3・転移の巻物 2 も使わずに終わった。
- **不足:** 取った技を使わざるを得ない局面。深さに比例した難度の上がり方（地下3〜7階はほぼ同じ手触りで、地下8階のトロルで急に致命圏）。
- **こうなれば動機になる:** 群れる敵が開けた場所で囲みに来る（扉口で 1 体ずつ受けられない）部屋、回復を強いる持久戦（毒の階、長い守護者戦）を用意する。特技の後半に「強打で朦朧にした敵へのなぎ払いは会心」のような組み合わせを出し、ビルドが形になる瞬間を作る。

### 発見と驚き
- **現状:** 初見の種族（洞窟トロル）が「大柄・遅い・重装」と出た瞬間の緊張は良かった。活力の薬（最大 HP +3）を 3 本見つけたのも嬉しかった。祭壇で鑑定がまとめて済むのも気持ちいい。ただ、階の名前（石の広間・苔むした遺跡・湿った洞窟）は名前だけで、遊びが変わらない。泉は一度も使わなかった。
- **不足:** 階ごとの特色、珍しい部屋、一度きりの出来事。
- **こうなれば動機になる:** 「この階には◯◯の巣がある」「封印された扉の奥に宝」のような、寄り道するかを選ぶ小目標を階に 1 つ置く。

### 目標の階層（短期・中期・長期）
- **現状:** 短期（目の前の戦闘）と中期（遠征の目的）ははっきりしている。長期は「確定点の合計」しかない。
- **不足:** ランの節目（例: 地下10階到達、守護者 5 体撃破）や、次の遠征で何が変わるかの見通し。
- **こうなれば動機になる:** キャンプに「次の節目まであと何か」を出す（例: 「地下10階の聖域まであと 2 階」）。節目で開くもの（キャンプの施設、候補の枠の追加）があると、遠征を重ねる理由になる。

### 物語・世界観
- **現状:** 遺物は 2 回とも「古の遺物」、守護者は「守護者ゴブリン」で、名前に物語が無い。thought を書くとき、語ることがスコアの話しか無かった。
- **不足:** 遺物や守護者の固有名と一言の由来、持ち帰った遺物がキャンプに残ること。
- **こうなれば動機になる:** 遺物に固有名と 1 行の伝承を付け、キャンプに飾られ、次の候補の文に繋がる（「◯◯の欠片を持ち帰った。残りは地下8階に」）。

### 達成感のフィードバック
- **現状:** 遠征の終わりに出る「確定 +8170。内訳: 目的5175・宝213・賞金480・発見450・撃破218、倍率 ×1.25」は分かりやすい。
- **不足:** その数字が良いのか悪いのかの基準。
- **こうなれば動機になる:** 「この枠・深さでの自己ベスト」「前回の遠征との比較」を 1 行添える。

### 不確実性と推理
- **現状:** 外見名の薬・巻物、命中の記録、推定残り HP は推理の材料として機能していた。
- **不足:** 遺物探しが総当たりの探索になる（気配は 8 方向と近い・遠いだけ）。指輪のような得失のある装備の欠点の効き目が見えない。
- **こうなれば動機になる:** 気配の距離を 3 段階にする。音で敵が起きたときは原因を出す。推理した結果が当たったと分かる場面を増やす。

### 記録と比較（自己ベスト）
- **現状:** 確定点と達成した遠征の数しか見えない。
- **不足:** 遠征の履歴、ランの自己ベスト、ほかのランとの比較。
- **こうなれば動機になる:** キャンプの表示に「これまでの遠征（枠・結果・点）」を短く並べる。list_runs などで過去のランの最高点が見られる。

### 他プレイヤーとの関わり
- **現状:** ソロでは何も無い。thought が観戦画面に出るらしいが、反応は返ってこない。
- **不足:** 誰かが見ている・同じ世界を誰かが遊んでいる手応え。
- **こうなれば動機になる:** 同じシードの他プレイヤーの記録（「この階で倒れた冒険者がいる」の痕跡や墓標）、観戦者からの簡単な反応。

### 上位 5 つ（重要度順）
1. **ビルドの手応えが弱い。** なぎ払い・立て直しは 0 回、薬・巻物も温存したまま。取った技や持ち物を使わざるを得ない局面が来ない。
2. **枠の難度表示と中身が噛み合わない。** 格3守護者が体力 19 のゴブリン、無防備の遺物が階段から 3 歩。遺物と綱の組み合わせで野心が安全側に寄り、3 択の重みが薄い。
3. **難度の上がり方が階段状で、危険の原因が見えない。** 地下3〜7階は装甲 4 で作業になり、地下8階でトロルの一撃 17 と、周囲の一斉の目覚めで急に致命圏になった。なぜ起きたかが分からない。
4. **長期目標と記録が無い。** 確定点の合計以外に、遠征を重ねる理由（節目・解放・自己ベスト・履歴）が無い。
5. **発見と物語が薄い。** 階の個性、寄り道の小目標、遺物や守護者の固有名と由来が無く、thought に書くことがスコアの話だけになる。

## 5. 情報量とトークン効率

- **1 応答はおおむね 2〜4 KB。** 長くなる要因は次の 4 つ:
  1. `【遠征N】…` の見出し行（約 250 字）が毎回出る。中身は変化が無い限り同じ。
  2. 所持品の行が、何か拾うたびに全体で出る（ガラクタ込みで 17 品）。
  3. valid_actions の `equip a / equip b / equip i / equip j / equip k / equip r`（ガラクタの装備候補）と、毎回出る綱の長い説明。
  4. 見えている敵ごとの命中の記録。例: 「あなたの命中 近接38/43・相手の命中 11/22・近接の通り 平均4.0／38回」が、眠っているゴブリンにも出る。戦闘中に見えている敵が 8 体いた応答は特に長かった。
- **冗長だと感じた点:** 見出しの遠征行（変化が無ければ短縮してよい）、眠っている・遠い敵の詳細な記録（脅威と体力の目安だけでよい）、劣る装備の equip 候補。
- **足りない情報:**
  - 遺物に守護者がいるかどうか（遠征 2 の開始時）。
  - 盾の構えなどの特技が、マクロの中のどの手番で効くか。
  - 敵が起きた原因（騒音・指輪）。
  - 重い鎧（歩く手番 110）を着たときの「追ってくる敵にあなたより速いものはいない」の扱い（歩く速さで比べているのかどうか）。
- **良かった点:** 地図は変化があったときだけ付くので負担が小さい。「直前の出来事」は戦闘の流れが追えて有用。recall の 1 行要約はちょうどよい長さ。

1. **explore toward:draft が 200 手往復する（2 回再現）。**

   - 再現 2: 同じ遠征。地下6階の上り階段 (26,11) から `explore toward=draft`（下への風: 西）。200 手後に (17,20) で上限に達し、探索は「約 1/4」のまま。直後に普通の `explore` を呼ぶと 14 手で下り階段を見つけた。
